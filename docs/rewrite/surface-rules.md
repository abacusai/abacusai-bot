## Title-bar alignment

The artifact's TopBar, TitleMac and TitleWindows boards define a 40px row, 28px controls and tabs, and 16px control glyphs. Shared chrome tokens give controls an 8px radius, 4px within-group gaps, 8px between groups and 1.75px icon strokes. Controls and tabs centre vertically with 6px above and below; labels use the existing 13px type scale. TitleBarGroup and TitleBarIconButton own this geometry. Native `--titlebar-x` / `--titlebar-end` reserve traffic lights and caption buttons; no feature guesses these insets. The brand follows navigation/sidebar controls; context follows the leading group. The one live bot identity travels from this context slot into the transcript. Tabs stay inside WorkspaceTitleRegion, aligned with the visible tool island (or main island without tools), with reachable controls at its right. Tab count never changes the leading/context geometry.

Dock hosts have zero outer padding. Dockview’s native theme gap uses the shared 8px token only between groups; the shell owns the outer inset once. Saved overlay layouts migrate to inline hosts on restoration.
