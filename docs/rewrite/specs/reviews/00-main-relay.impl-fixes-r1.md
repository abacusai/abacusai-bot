**Goldens.** The gate holds: no `.ndjson` file changed, `ndjson-golden` passes all 24 scenarios, and under `--wire agui` every scenario's compat stream still equals its `.ndjson` baseline byte for byte. One AG-UI golden changed, deliberately: `bot-no-model.agui.jsonl` gains

```
{"type":"TEXT_MESSAGE_START","messageId":"srv-<1>:error","role":"assistant"}
{"type":"TEXT_MESSAGE_END","messageId":"srv-<1>:error"}
```

right before its `RUN_ERROR`. It is the only scenario whose failing run had no assistant message of its own (`turn-failed`, `openllm-exhausted` and `stall-twice` each open one before the error), so it is exactly the case of Claude 1. The other agent tests that changed assert the same thing on the exit paths: `emergencyClose` now writes the anchor pair and the terminal in one write, and the compat-loss paths (in-process and spawned) end with the closed open message or the anchor, then `RUN_ERROR`.

**Test counts** (all green): desktop `--project main --project preload --project shared --project main-serial`: 253 files, 2758 passed, 4 skipped, 7 todo. Agent: 122 files, 2029 passed, 5 skipped. In two full runs one timing-bound test failed each time, a different one (the `session.integration` OpenLLM retry budget, then a 5 s parser test timing out under load); each passes alone, and neither is touched by this change. `tsc -b` (desktop, agent), `tsc -p tsconfig.test.json` (agent), root `oxlint .` (0 errors) and `oxfmt --check .` are clean; knip reports nothing under `src/main` or `src/shared`. PARITY.md regenerated with `UPDATE_PARITY=1`: unchanged (no `ai.*` entry in the legacy map).

**Tests fail without their fix.** For the central ones this was checked by mutation after the fix: removing the anchor or the tool closure fails the two terminal tests in `thread-relay.test.ts` and the spawned kill-in-a-tool e2e; an `await` between the duplicate check and the reservation, dropping the runtime filter on exit, dropping the overflow detach, or ignoring the epoch each fails its `relay-service.test.ts` test; removing the stdout flush at close fails the `cli-manager-wire` last-line test. The others test APIs or behaviour that did not exist before (`defaultWire`, `clearByMain`, `expectEcho`, `NOT_FOUND`, finished-log TTL, `queue.update`).
