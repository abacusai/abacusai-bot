1. **Blocker. §10.1 W9 conflicts with §§11.4/13 and R6-T30.** The spec sets `backgroundThrottling: false` while relying on `document.visibilityState === "hidden"` to pause dwell clocks and detect full-screen suppression. Installed Electron typings explicitly warn that this option affects Page Visibility; [Electron documents](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility) that disabling throttling keeps visibility `visible` even when hidden or occluded. The banner feature flag does not protect dwell expiry or audible-document selection. **Fix:** retain background throttling, or supply an independently verified visibility signal for every affected consumer. Test actual `WebContentsView` hide, occlusion and Space changes with the shipped options.

2. **Major. §12.5 invalidates successful dictation.** End must stop recording, transcribe and insert the result, but the operation-token rule explicitly makes **End** mark that operation stale. The same rule then discards its transcript. **Fix:** End transitions the current operation from recording to transcribing without invalidating its token. Cancellation, unmount and session replacement invalidate it. Extend R6-T21 to assert that normal End inserts exactly one transcript.

3. **Major. §§11.2/23.6 do not define a consistent `ai.attention` snapshot-to-live protocol.** Separate snapshot and coalescing subscription calls can miss a permission change between them, or apply an older snapshot over a newer event. No initial snapshot, revision boundary, removal payload or reconnect procedure is specified. A stale question classification can survive until another update. **Fix:** define an atomic initial snapshot plus live subscription, or a revisioned subscribe-first buffering protocol. Specify zero-count/removal events and resets on incarnation change, session deletion and reconnect. Add these races to R6-T44.

4. **Major. §11.2 declares the wrong incarnation type.** `AttentionSummary.incarnation` is `number`, but the implemented [thread snapshot](/Users/rajaniraiyn/work/abacusai-bot/apps/desktop/src/shared/contract/ai-thread.ts:68), permission lineage and agent wire use string incarnations. These are opaque process identities, not numeric counters. **Fix:** use the existing string incarnation type, preserving its value unchanged. Type-check and test summaries across process replacement.

5. **Major. §10.6 preserves the old view without isolating the replacement’s native mutations.** Both documents are registered as `notch` and run directors against the same `BaseWindow`. Under §§10.10/11.6, a hidden replacement can call `setShape` and hide, show or resize that window before readiness, clipping or hiding the still-active old document. `View.setVisible(false)` only hides the replacement view. **Fix:** distinguish active and standby contents in main. Stage standby shape reports and reject its interaction, focus, presentation and cue claims until promotion. Atomically transfer ownership and apply staged bounds. R6-T25 must exercise conflicting shape reports during delayed and failed swaps.

6. **Major. §8.3’s idempotent deletion handles only the server-side missing-row case.** Installed TanStack DB throws `DeleteKeyNotFoundError` synchronously when `collection.delete(id)` targets a locally absent row, before creating a transaction or calling RPC. The reference clone does the same. Treating RPC `NOT_FOUND` as success therefore does not cover a routine deleted elsewhere or an echoed deletion encountered during retry. **Fix:** treat local absence and the typed DB error as completed deletion, alongside RPC `NOT_FOUND`. Extend R6-T9 with an already-absent routine and deletion arriving between attempts.

7. **Major. §14.2’s fallback can grant an unplayable claimant.** The audible-document selection requires an unlocked context, but the fallback grants the earliest *other* claimant without that eligibility requirement. §14.4’s listed pre-claim gates do not exclude locked contexts. An earlier locked notch can consume the sole grant while a later unlocked document receives `false`, losing the cue. **Fix:** prohibit locked documents from claiming and recheck readiness, audio unlock, visibility and document ownership before a fallback grant. R6-T22 needs mixed locked/unlocked claimants and disposal during the fallback delay.

8. **Major. §10.1 W3 omits the documented prerequisite for `skipTransformProcessType: true`.** The spec selects it solely to avoid Dock flicker. Installed Electron typings and [the API documentation](https://www.electronjs.org/docs/latest/api/base-window#winsetvisibleonallworkspacesvisible-options-macos-linux) describe bypassing the transformation when the process is already a `UIElementApplication`; this app is a normal foreground application, and no conversion is specified. **Fix:** remove the bypass unless that prerequisite is established. Test visibility across ordinary Spaces while preserving the main application’s Dock and activation behavior.
