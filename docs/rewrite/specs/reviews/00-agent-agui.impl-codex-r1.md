1. **major — `packages/agent/src/agui/queue.ts:184`** — A stdin line containing valid JSON `null` now kills both hosts. The new `command.type` access throws outside the handler’s rejection catch; the legacy host caught this error and continued. **Fix:** validate the parsed command before classification, preserve the legacy error response, and add a baseline case containing `null` followed by a successful send.

2. **major — `packages/agent/src/agui/host.ts:325`** — Retrying with the same user-message id corrupts continuous transcripts. The host echoes the full text again; TanStack’s `StreamProcessor` retains the existing accumulator and appends it. A probe against the installed library produced `"questionquestion"` after two runs echoing `"question"` under the same id. Main’s transcript processor and subscribed second windows are affected. **Fix:** make user-input replay idempotent and test failed/cancelled run → retry through a continuous processor.

3. **major — `packages/agent/src/agui/host.ts:352`** — A rejected preparation operation leaves `busy` and `preparing` held and its run open forever. Real `BotSession.setModel()` can propagate pi’s rejection. Execution never reaches `runHeld()` cleanup; the outer catch records failure without settling the preparing run. **Fix:** contain preparation failures under the specified nonterminal command-error policy, then continue or release the admission with owner-checked cleanup. Test rejection followed by another send.

4. **major — `packages/agent/src/agui/queue.ts:273`** — Reset does not reserve admission while replacing the session. When reset starts while idle, a concurrent `run` sees `busy === false` and can prompt the session being aborted or disposed. Reset subsequently clears `busy` even if that newer run owns it. Idle Stop has the equivalent hole at line 401. **Fix:** reserve AG-UI admission throughout Stop/reset and make completion cleanup generation-owned; test idle reset/Stop racing every turn starter while preserving default-wire behavior.

5. **major — `packages/agent/src/agui/queue.ts:509`** — A thrown `session.send()` settles its token before the command catch records the failure. This emits `RUN_FINISHED success`, followed by a nonterminal error. The catch also identifies ownership only by command type, so a queued command’s steering failure can mark another command’s open run failed. **Fix:** associate exceptions with the admitted token and record owner-valid failure before settlement; commands without their own open run must emit `agent.error`.

6. **major — `packages/agent/src/agui/host.ts:203`** — Compat loss writes its notification and terminal through asynchronous stdout writes, then immediately calls `process.exit(75)`.
