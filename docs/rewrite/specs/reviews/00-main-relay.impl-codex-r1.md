10. **Major — [relay-service.ts:453](/Users/rajaniraiyn/work/abacusai-bot/apps/desktop/src/main/services/agui/relay-service.ts:453).** A retained started ack plus absence from completed history is treated as a current run. Cancelling an older completed run can therefore mark an unrelated current turn stopped, suppressing its messaging, artifact, routine-settle, and turn-waiter compat traffic. Track admissions awaiting `RUN_STARTED` explicitly; otherwise mark stopped only for the active or pending run.
