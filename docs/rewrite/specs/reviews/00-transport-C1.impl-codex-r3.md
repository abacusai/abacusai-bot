1. **Major**, `apps/desktop/src/main/services/session/thread-store.ts:196`. An unreadable or corrupt archive index becomes an empty index. On a later partial run, step 4 consequently removes previously archived threads’ valid twins as orphans. **Fix:** return empty only for genuine absence; fail the migration plan on index read or validation errors.

2. **Major**, `apps/desktop/src/main/services/session/transcript-service.ts:65`. TranscriptService and ThreadStore have separate `HeldFiles` memory maps. When the journal is blocked or cannot be written, ThreadStore cannot see the held v1 save. Hydration flushes the new twin, compares it against old disk v1, and repairs it backward. **Fix:** share one `HeldFiles` instance between both services, including memory fallback state.

3. **Major**, `apps/desktop/src/main/services/session/thread-store.ts:140`. The ownership peek matches nested `"source":{"kind":"transcript-v1"}` anywhere in the header. A version-2 foreign twin with top-level `source.kind: "future"` and that nested metadata passes the fast path and is overwritten by dual-write. **Fix:** verify the top-level source with structural parsing or a strictly validated writer-format header; otherwise use the full ownership parser.
